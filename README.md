# shearunit

Shear URLs and unit query parts with stable normalization.

**Site:** https://theworker02.github.io/shearunit/

## Install / run

```bash
git clone https://github.com/theworker02/shearunit.git
cd shearunit
node src/cli.js
node --test
```
